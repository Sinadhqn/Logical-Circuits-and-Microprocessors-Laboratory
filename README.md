# Logical Circuits & Microprocessor Laboratory Projects

A collection of academic laboratory projects developed and simulated using **Proteus** as part of my B.Sc. Computer Engineering coursework.

The repository contains practical exercises covering **digital logic circuits, combinational and sequential circuits, microprocessor interfacing, memory, input/output devices, and embedded systems**.

## Project Structure

### Logical Circuits Laboratory

The Logical Circuits section contains digital circuit design and simulation projects, including:

1. Basic Logic Gates
2. 7-Segment Display
3. Half Adder & Full Adder
4. 4-Bit Adder/Subtractor
5. Adder/Subtractor Comparison
6. BCD Adder
7. Multiplexers
8. Up/Down Counter
9. Multiplexer / Demultiplexer / Switch

### Microprocessor Laboratory

The Microprocessor section contains practical projects involving microprocessor-based systems and peripheral interfacing:

1. 7-Segment Display
2. Keypad Interface
3. Character LCD
4. EEPROM
5. EEPROM & Keypad
6. Stepper Motor
7. Graphic LCD (GLCD)
8. Temperature Measurement
9. Programmable Peripheral Interface (PPI)

## Repository Contents

Each project includes the corresponding Proteus simulation files and, where applicable, supporting files and documentation.

The main project file format is:

- `.pdsprj` — Proteus project files
- `.hex` — Microprocessor program files
- `.pdf` — Project documentation and circuit output
